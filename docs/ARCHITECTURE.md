# QQ bot 与根路径管理面板

运行入口 `main.py` 启动一个 Uvicorn worker。`app.main` 通过 lifespan 创建 Runtime；`qq_bot.QQAdapter` 仅管理经过 token 认证的 OneBot 连接。浏览器与 NapCat 断线都不会销毁核心。生产数据目录的实例锁阻止同时启动两个进程。

## 输入与投递

QQ 入站先在 `messages` 和 `turn_jobs` 持久化，去重键包括机器人、群号和外部消息号。处理阶段为 `queued → processing → prepared → stored → generated → finished`，失败/忽略/过期另行记录。

`prepared` 保存理解结果和已校验向量。`stored` 与记忆/关联/概念在同一 SQLite 事务提交。内部思考记忆与 `generated` 决策也在同一事务提交。失败处理按已有阶段恢复，避免重复建立输入记忆。

公开回复先保存到 `delivery_outbox`，包含固定目标、内容、回复向量和有效期。echo 与 ACK 独立于模型线程处理。渠道明确接受后，公开记忆、历史、发送指标和 `delivered` 状态在同一事务提交。超时/断线/进程中断造成的未知发送标记 `unknown`，不会自动重播。明确失败的投递可由管理员请求重试，使用原内容；并发投递共用异步锁并重新读取状态，避免两个请求发送同一记录。

OneBot ACK 证明渠道接受动作，不证明最终用户阅读。平台没有端到端的幂等投递承诺，服务选择保守处理未知结果。

睡眠时仍推进节律并优先检查新输入，避免待回复任务阻挡新的 `@` 唤醒消息。处理期限随 contextvars 传入模型/向量请求，后续请求不得超过任务有效期。暂停和重新连接时也检查任务有效期。

## 持久化与事务

`core.memory_engine` 使用同一 CoreConnection 执行记忆、关联和概念事务。内部 `commit()` 在外层事务中延迟到最终提交；失败时回滚数据库、重建 FAISS/关键词/概念缓存并恢复统计。向量必须在事务前满足维度、有限值、非零要求。

应用的核心执行器为一个线程；管理写入与 QQ 认知通过它串行执行。模型调用移出 asyncio 事件循环，多模态请求拥有独立客户端，不会被配置重载关闭。保存与睡眠维护共用一个 RLock，消除相反锁顺序。JSON 导出使用独立临时文件、fsync 和原子替换，保存失败不推进节流。

SQLite 为事实来源，FAISS/关键词索引在启动时从完整数据库重建。旧 JSON、FAISS 和 clock 文件不决定恢复。召回强化立即更新 SQLite，维护只淘汰确认使用 Unix 时间且已过期的记忆。历史以数据库自增序号翻页/导出，不使用长度为 200 的列表作为持久化游标。

管理消息、会话、任务和审计另用 Repository 连接，采用 WAL/FULL；它们与核心事务共用同一数据库文件。核心事务涉及阶段检查点时直接使用核心连接，避免另一个 writer 在事务内等待。

## 群范围与管理

群状态存于 `QQConversationService.groups`；contextvars 将群、来源、外部消息标识传入核心线程。群记忆仅当前群可见，显式 `persona_shared` 资料可跨群检索，旧 `legacy_unattributed` 记录只供管理员检查。检索在允许范围内排名，关联扩散和概念也校验群范围。素材/笔记位于 `groups/<group_id>/`。

网页只有管理功能。登录使用 PBKDF2 密码哈希和服务器端会话；管理写操作校验 Origin/CSRF；事件流与附件/备份下载也需要管理员会话。会话撤销、修改密码会使旧会话失效。不存在网页对话、客户账号、跨渠道身份绑定、训练或聊天测试 API。

静态资源由同一 FastAPI 服务提供，管理首页为 `/`。未知 API/页面返回 404，`/admin` 不存在。内部 OneBot WS 位于 `/internal/onebot/ws`，公网反向代理应拒绝 `/internal/*`。

## 迁移与运行限制

离线工具持有与运行时相同的实例锁。迁移先备份，再修改暂存数据库，并保留原 ID 与原时间字段。时间证据不足时保留未知标记；仅按显式字段映射转换旧 QQ 虚拟时间，不偏移原本真实的概念字段。重新嵌入先验证全部新向量再发布，异常中断通过标记阻止混用配置和数据库。

当前仅一个进程/worker、一个角色、一个 QQ 账号与群聊。不支持分布式认知协调、多 worker、QQ 私聊或角色托管。群范围检索按允许集合构造索引，仍需以实际数据规模做性能评估；本轮自动测试不替代长期负载与真实模型/QQ 联调。
